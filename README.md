# Prediction of CO2 Level using Linear Regression 
**Algorithm used:** y = mX + c ==> Linear Regression
Predicted the level of CO2 with the number of Trees planted in 10Yards of areas.
This is my first practice project on Supervised Learning and alogrithm used is Linear Regression.
**Steps are as follows:**
1. Data Seeding. Generating Random data
   X = Number of Trees in 10 Yard Area. (independent Variable)
   y = CO2 Level (dependent Variable)
2. Data Preprocession. Removing missing values and outliers
3. Exploratory Data Analysis. Reading graphs about data.
4. Splitting of data into Training and Testing. 80% of Training and 20% of Testing.
5. Giving Training data to Model.
6. Then testing the model on Testing Data.
7. Evaluation of model by Mean Squared Error (MSE) & R2 (r-squared).
At the end plotting the regression fit Line to see how much model trained.
